# Contributing

FlowBench is a small, single-author project with a bounded v0.1 scope. Contributions
that keep it small are welcome.

## Setup

```bash
uv sync --frozen
uv run pre-commit install
```

## Before opening a pull request

```bash
make lint   # ruff check, ruff format --check, mypy --strict on src/
make test   # pytest; no network, no real data
```

Both must pass. CI runs the same commands on CPU.

## Conventions

- **Commits** follow [Conventional Commits](https://www.conventionalcommits.org/):
  `feat(data): simulation-level splitter with persisted IDs`.
- **Configuration** is typed and lives in `configs/*.yaml`; no magic constants in code.
- **Type hints** everywhere; `src/` passes `mypy --strict`.
- **Docstrings** are Google style on public functions.
- **Logging**: use `flowbench.logging.get_logger`; no `print` in library code.
- **Tests** use tiny synthetic fixtures from `tests/conftest.py`. Do not add tests
  that need the real dataset or the network.
- **Scope**: v0.1 is persistence vs a 4-layer CNN on 32×32 vorticity. FNO,
  autoregressive rollout and higher resolutions belong in the roadmap, not in
  pull requests, until a release is planned for them.
- **Numbers in docs** are generated by `flowbench evaluate` and copied from
  `artifacts/`. Never edit a benchmark figure by hand.

## Reporting bugs

Use the bug report template; include the config file, the command, and the
`data/manifest.json` if the issue is data-related.
